# Circuit Cube demo video

`circuitcube-1.4.0-demo.mp4` (97 s, 720x1482, 30 fps, no audio) shows Circuit Cube version 1.4.0 (build 7), recorded on 2026-11-23 from the Unity Editor Game view (2960x1440 portrait) running code equivalent to `main`. It shows the home screen; Moonbase level 1 played tile by tile to a win and its result screen; Moonbase level 12, a full cube with 54 tiles, turned and solved to its result screen; the leaderboard screen (This week and All-time tabs, filled with the debug sample boards because the editor has no live entries); and a switch from the dark to the light theme, with the light home screen and Moonbase level 3 played and won in light. The tile taps were scripted through the game's own tap handler in Play mode, so the moves, lamps and results are the real game logic; the cube turns between faces are short scripted flings.
