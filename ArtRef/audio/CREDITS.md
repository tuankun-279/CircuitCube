# Audio credits

Every sound in `Assets/CircuitCube/Audio` is CC0 (public domain): free for commercial use, no credit required.
Credit is still given here and in the game's About text.

## Effects: Kenney (kenney.nl), CC0

| Game event | File | Source |
|---|---|---|
| Rotate a tile | Sfx/rotate.wav | Interface Sounds · click_001 |
| Lamp lights (pitched per colour) | Sfx/lamp.wav | Interface Sounds · confirmation_001 |
| Level complete | Sfx/win.wav | Interface Sounds · confirmation_002 |
| Star on the result card | Sfx/star.wav | Digital Audio · powerUp5 |
| New shape unlocked | Sfx/unlock.wav | made from Interface Sounds · confirmation_001, four notes up (C E G C) |
| Hint | Sfx/hint.wav | Digital Audio · phaseJump3 |
| Undo | Sfx/undo.wav | Interface Sounds · click_001, reversed |
| Locked tile / level / shape | Sfx/blocked.wav | Interface Sounds · error_001 |
| Buttons | Sfx/button.wav | Interface Sounds · select_002 |
| Card opens / closes | Sfx/panel_open.wav, panel_close.wav | Interface Sounds · open_001, close_001 |

All effects: silence trimmed at both ends, 8 ms fade-out, mono, peak level set per role
(rotate, button, undo −12 dBFS; panels −13; lamp −8; star, hint −9; blocked −10; win, unlock −5).
